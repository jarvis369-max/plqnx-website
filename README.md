# Plqnx Java (APK build branch)

A lightweight offline Android WebView wrapper containing 90 fully embedded Java exam-preparation questions and answers. No network access or API keys. Soft-peach design. Questions are based on the user-supplied AP SBTET C-23 AIM-302 guide.

Build: GitHub Actions > Build Plqnx Java Android APK, or locally using Java 17 / Android SDK 35 / Gradle 8.9 and `gradle :app:assembleDebug`.

Installation APK: app/build/outputs/apk/debug/app-debug.apk

Source for full offline HTML: app/src/main/assets/index.html

This branch is isolated from the existing plqnx-website main branch.

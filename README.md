# PLQNX CORE — Receivables AI

PLQNX is now focused on one product direction: a B2B receivables command center for Indian manufacturing MSMEs.

The public website no longer presents PLQNX as a general-purpose chat assistant or a family of unrelated AI concepts. CORE now demonstrates the workflow described in the founder blueprint:

- receivables portfolio and ageing
- daily prioritized collections queue
- customer ledger
- evidence-grounded reminder drafting
- human approval
- promise-to-pay and dispute tracking
- outcomes and collection metrics
- CSV/Tally-style import flow
- auditability and tenant-isolation principles

## Product boundary

Version one is ordinary B2B SaaS. It does **not** move customer funds, lend, factor invoices, operate TReDS, approve loans, or perform autonomous legal recovery.

## Status

This repository is a pre-launch website and interactive front-end demonstration. Production use still requires a secure backend, authentication, tenant-safe storage, integrations, monitoring, contracts, privacy/security controls, and professional legal/accounting review.

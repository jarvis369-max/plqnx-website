# PLQNX

**From the Smallest to the Infinite**

PLQNX is an independent, pre-launch AI startup project inspired by the Planck scale. This repository contains the public website and a *scripted* demonstration of PLQNX CORE. The demo **does not** call an AI API.

## Preview locally

Open `index.html` in a modern browser. No build tools, package installation, API key, or paid service is required.

## Publish on GitHub Pages

1. Open **Settings → Pages** for this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then click **Save**.
4. Once GitHub completes deployment, the usual project URL is:
   https://jarvis369-max.github.io/plqnx-website/

The URL above is the expected address after Pages is enabled; it is not a claim that publication is already active.

## Prototype and privacy

The interactive assistant is entirely scripted in the browser. It does not send messages to a server, call an AI provider, or persist chat messages. Do not advertise it as a live AI product. A live beta should use an authenticated backend, server-side API secrets, rate limits, and an accurate privacy policy.

## Brand and legal status

PLQNX is a proposed brand for an **unregistered, pre-launch project**. Company name, domain, and relevant trademark clearance should be completed before commercial launch. This website must not imply that an Indian private limited company has already been incorporated.

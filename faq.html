FREQUENTLY ASKED QUESTIONS · PRE-LAUNCH

Good questions.
Clear answers.

Everything visitors and early testers should know about our current invite-only beta.

What is PLQNX?

PLQNX is an independent, pre-launch AI startup project. CORE is our first working AI assistant, available to invited testers.

Can everyone use the public website?

Yes. Everyone can visit the homepage, read about the project, explore future concepts and open the scripted preview. The live CORE chat still requires an invitation and account.

How do I access the beta?

If you have a private invitation code, open CORE, choose Create account and enter your code, username and password. Beta registration is limited to five accounts. An existing user can simply sign in.

Does CORE save my conversations?

Yes. Signed-in users can revisit stored conversations, rename them, search recent chat titles and export loaded messages. The beta currently loads up to 150 messages per conversation. For responses, it references a limited recent-message context, not unlimited memory.

What languages are supported?

CORE can respond in English and Telugu, though the accuracy and fluency of AI-generated responses can vary.

What is the daily limit?

The current beta allows up to 25 AI requests per account per day, subject to service availability. Limits may change as the beta evolves.

Is CORE free?

CORE currently has no subscription charge for invited testers. There is no published paid plan or public-launch pricing.

Can I upload files, generate images or use autonomous agents?

Not in the current CORE beta. These are possible directions for future testing and should not be treated as available features today.

Is PLQNX already incorporated?

No. PLQNX is currently a proposed brand for an independent, pre-launch AI project.

How are my conversations handled?

Account data and chats are stored using the project's backend and database. Chat messages are sent to an external AI service to generate responses. Do not send passwords or sensitive personal information. Read the beta privacy notice for details.

Does CORE work in the background when I leave?

The public website can remember your recent commands on this device only if you enable local memory. That is not background AI activity. An optional scheduled AI-brief feature has been prepared for the private beta but is inactive until the Cloudflare Worker and cron schedule are deployed. If activated, it requires your explicit opt-in and a topic you choose.

How do I report an issue?

Visit the feedback page to prepare a bug report. A public support inbox has not yet been announced.
